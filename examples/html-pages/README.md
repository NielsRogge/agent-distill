# html-pages: interactive single-file HTML pages

> **Status: paused (2026-11-25).** Kept as a documented attempt; published traces, adapter, and merged model remain public.

Distill a frontier agent that builds self-contained, interactive single-file HTML pages into a small open model inside `pi@1.6.0` (design in [docs/DESIGN.md](../../docs/DESIGN.md#10-example-2-stunning-html-pages)).

## Why it was paused

1. **Not genuinely agentic:** 97% of the teacher's tool payload was a single initial `write` of `index.html` (~66 KB median), followed by at most one tiny edit (~1.2 KB). `./preview` surfaced an issue in only 35 of 472 accepted traces. In practice, the student had to learn one-shot 15–25k-token code generation without a single JS error rather than an iterative agent loop.
2. **SFT failed to transfer:** Qwen3.5-9B (base and SFT) passed **0** test concepts.
3. **Unvalidated GRPO judge:** against 50 blind human pair labels, no tested vision-judge setup agreed with human preference significantly better than chance (`p >= 0.12`).

## Results

### Teacher baseline (60 validation concepts)

Evaluated in `pi@1.6.0`, rescored with the motion-aware Gemini 4 Hydrogen judge and the `submitted` gate (all episodes including reruns):

| Teacher | Passed | Submitted | Mean reward | Baseline cost | Median time |
| --- | ---: | ---: | ---: | ---: | ---: |
| **Kimi-K3.1-Pro** | **58/63** | 59/63 | 0.748 | $52.67 | 7.0 min |
| GLM-5.3 | 10/80 | 14/80 | 0.124 | $36.97 | 10.6 min |

Kimi-K3.1-Pro reliably previewed, fixed, and submitted within limits. GLM-5.3 frequently hit the 15-minute timeout, 30-call limit, or 65k output limit before calling `submit`.

### M5 distillation run (Kimi-K3.1-Pro → Qwen3.5-9B)

- **Traces:** Kimi passed 478/600 train concepts (80%, $582.99); 472 reached SFT (`nielsr/qwen35-9b-html-pages-kimi-k31-pro-pi-160-traces`).
- **SFT:** Qwen3.5-9B LoRA (`r=32`, 1 epoch, reasoning dropped; loss plateaued at ~0.50).
- **Test evaluation** (120 held-out concepts):

| Student | Episodes | Passed | Submitted | Passed gates | Judge ≥ 7/10 | Median judge |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Qwen3.5-9B (base) | 120 | 0 | 72 | 83 | 0/83 | 2/10 |
| + SFT (stopped early) | 38 | 0 | 15 | 8 | 0/8 | 2/10 |

48/120 base episodes hit the 30-call limit; SFT was stopped after 38 episodes (12 timeouts, frequent JS load errors and garbled shell commands). During the first SFT evaluation, an agent episode deleted the stage's records — which prompted adding per-episode unprivileged UID isolation (`agent_distill.harnesses.isolation`).

### Judge calibration (50 blind human pairs)

50 same-concept Kimi vs. GLM pairs labelled blind (36 with a preference, 14 ties; reproduced by `calibration/score.py`):

| Judge setup | Agree / disagree / tie | Accuracy (of 36) | Spearman | Sign-test p |
| --- | --- | ---: | ---: | ---: |
| Gemini 4 Hydrogen, per-page, 3 stills | 16 / 9 / 11 | 0.60 | 0.15 | 0.23 |
| Qwen3.8-27B, per-page, 3 stills | 11 / 7 / 18 | 0.56 | 0.14 | 0.48 |
| Hydrogen, defect list + appeal | 14 / 15 / 7 | 0.49 | 0.04 | 1.00 |
| Hydrogen, pairwise, 3 stills | 22 / 13 / 1 | 0.62 | 0.19 | 0.18 |
| **Hydrogen, per-page, filmstrip + phone + activity log (current)** | **14 / 6 / 16** | **0.61** | **0.20** | **0.12** |
| Hydrogen, pairwise, filmstrip + phone + activity log | 20 / 12 / 4 | 0.61 | 0.19 | 0.22 |

The judge separates broken/weak pages from good ones (sufficient for trace acceptance), but does not reliably rank good pages against great ones, so GRPO was left opt-in.

## Task and rubrics

- **Concepts:** `nielsr/html-concepts` (~5k concepts across 12 categories generated by `concepts.py`, deduplicated; 5/category validation, 10/category test).
- **Episode:** Pi with `bash`, `read`, `edit`, `write`, and a local `./preview` CLI. Training is text-only: `./preview` runs headless Chromium for ~5 s and returns a text report (JS errors, network requests, blank render, animation, interaction response, mobile/desktop overflow). The agent submits `index.html` via Pi's `submit` tool (`FileAnswer`).
- **Rubrics (`rubrics.py`):**
  - **Gates:** `submitted` (ended cleanly via `submit`) and `page_ok` (passes sandboxed Chromium checks: loads cleanly, non-blank, zero network requests, no overflow).
  - **Vision judge (`page_quality`):** Gemini 4 Hydrogen (default; Qwen3.8-27B secondary) scores 1–10 from an 8-frame interaction filmstrip, phone screenshot, and sandbox activity log (`agent_distill/browser/sandbox.py`).
  - **Reward & pass:** `reward = gate(submitted, gate(page_ok, page_quality))`; passes when both gates succeed and `page_quality >= 7/10`.

## Running it

Local runs require a Chromium binary pointed to by `AGENT_DISTILL_CHROMIUM` (HF Jobs install Playwright Chromium via `Task.job_setup`).

```bash
# Brainstorm concepts
uv run python examples/html-pages/concepts.py --per-category 420 \
  --output concepts.jsonl --push nielsr/html-concepts --bill-to huggingface  # pragma: allowlist secret

# Teacher baselines on validation
uv run distill run examples/html-pages/run-teacher-baseline.toml --dry-run
uv run distill run examples/html-pages/run-teacher-baseline.toml --set teacher='"kimi-k3.1-pro"' --dry-run

# M5 distillation config
uv run distill run examples/html-pages/run.toml --dry-run
```
